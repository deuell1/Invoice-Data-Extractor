Perform a final Phase 1 QA hardening pass on the Invoice Data Extractor app.

Do not rebuild the app from scratch. Review the app against the Phase 1 checklist below and fix only missing or broken items.

Phase 1 checklist:
- User can upload PDF/image invoice.
- System generates a unique DocumentID.
- System stores original file unchanged in object storage.
- System creates an invoice record.
- System uses OPENAI_API_KEY from Replit Secrets server-side only.
- System performs live OpenAI extraction.
- System extracts VendorRawName.
- System extracts InvoiceNumber.
- System extracts InvoiceDate.
- System extracts DueDate or PaymentTerms.
- System extracts InvoiceTotal.
- System extracts PO number when visible.
- System stores ExtractionConfidence as a percentage or clearly mapped score.
- System stores field-level confidence where supported.
- System stores raw extraction JSON where supported.
- System matches VendorID from the controlled vendor table.
- System does not use OpenAI/OCR output to directly assign VendorID.
- System flags missing required fields.
- System flags low confidence below 85%.
- System checks duplicate VendorID + InvoiceNumber.
- System routes exceptions to the exception queue.
- AP reviewer can edit extracted fields.
- Edits create audit log records.
- AP reviewer can approve or reject.
- Approved invoices can export to CSV.
- User can manually enter VoucherID.
- Invoice can be marked Exported, if supported.
- Invoice can be marked Posted.
- Original invoice link remains available.
- Basic KPI cards are visible.
- Posted invoice count is visible.
- Total approved amount is visible.
- CSV export includes payment terms, subtotal, freight, vendor match score, and extraction confidence.
- Vendor aliases can be edited from Vendor Admin.
- Vendor on-hold status can be edited from Vendor Admin.
- On-hold vendors route to Exception.
- Extraction failure is visible and retryable.

Testing requirements:
- Test clean PDF invoice from known active vendor.
- Test JPG or PNG invoice from known active vendor.
- Test invoice with missing invoice number.
- Test unknown vendor.
- Test on-hold vendor.
- Test duplicate VendorID + InvoiceNumber.
- Test low-confidence extraction routing.
- Test due date before invoice date.
- Test invoice total missing or zero.
- Test CSV export opens cleanly in Excel.
- Test VoucherID entry and Posted status.
- Test Re-run Extraction.

At the end, provide a concise summary:
1. What was fixed.
2. What was tested.
3. Any remaining blockers.
4. Any recommended follow-up tickets.
