   export function isGraphIngestionConfigured(): boolean
     Returns true only if all four of GRAPH_CLIENT_ID, GRAPH_CLIENT_SECRET,
     GRAPH_TENANT_ID, and GRAPH_MAILBOX_ADDRESS are set and non-empty.
     Mirror the exact style of isExtractionConfigured() in
     extractionService.ts:70-72 — a simple, self-contained boolean check,
     no side effects.

   export function logGraphIngestionBootInfo(): void
     Mirror logExtractionBootInfo() (extractionService.ts:855-870) exactly
     in spirit: log at INFO level whether it's configured and which
     mailbox address is targeted, WITHOUT ever logging the client secret.
     If any of the four env vars are partially set (e.g. client ID present
     but secret missing), log a WARN calling that out specifically — a
     half-configured state is a likely real mistake, not a deliberate
     choice, unlike EXTRACTION_MOCK_MODE which has an explicit off switch.

   export interface FetchedAttachment {
