# Labeled Test Pack

Drop the labeled invoice files for the accuracy run here (PDF / JPG / PNG, plus at
least one multi-invoice PDF). These are kept alongside `../ground-truth.csv` for
record-keeping and reproducibility.

This folder is intentionally empty in the repository — no labeled pack has been
supplied yet, which is why the Phase 1 accuracy result is currently
**"Not measured — labeled test pack required."**
